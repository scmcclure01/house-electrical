Before you start

Open scmcclure01.github.io/house-electrical in Chrome or Edge. Firefox and Safari can't save back into your file.

  1. File → Open… and pick your house file. Yours is Dev House.json in Google Drive › My Drive › Claude › Personal › House Sketch and Electrical Panel. Next time, use File → Reopen.
  2. Click Save changes the first time Chrome asks to edit the file. After that, ⌘S saves in place with no dialog.
  3. A blue ● beside the file name means unsaved changes. Chrome warns you before closing with unsaved work.
  4. To experiment safely, use File → Load sample house. It isn't linked to your file.

Workflow

Work in this order: draw, place devices, set up panels, map circuits, link switches, print. Save with ⌘S as you go.

  1. Draw the first floor (Plan view, First Floor).
    • W, click a corner, point the mouse along the wall, type the tape-measure length (12'6, 12 6 or 150) and press Return. Repeat for each wall; the loop closes when you get back to the start.
    • I for interior walls. Click existing corners; they snap.
    • A and click each room's corners, then the first corner again. Type the room name. Change Area type in the strip for garage, attic or exterior.
    • T outlines the stair opening. D N O add a door, window or opening; set width, distance from wall end A, hinge and swing on the right.
  2. Draw the second floor. Click Second Floor, tick Ghost, and trace over the blue outline of the first floor so walls and stairs line up.
  3. Place devices. Press a device key (page 4) and click near a wall; wall devices snap to it facing into the room. Ceiling lights snap to the room's center. Set GFCI/AFCI, switch type or light type in the strip first, or later on the right.
  4. Number devices. When the plan is complete, click empty space, then Renumber all devices… on the right so numbers run room by room.
  5. Set up panels (Panels view).
    • Click a panel's dark header: name, code, spaces, brand, model, ratings, location.
    • + Add panel adds a subpanel; set Fed from to its 2-pole feeder breaker.
    • Click a + slot to add a breaker; type its label, set amps, poles, type and model.
  6. Map circuits. Select a breaker → Assign devices on the plan… (or B on the plan and pick the breaker top-left). Switch that breaker off, walk the house, and click every device that went dead. With Mark verified ticked, each click also marks it verified.
    • Show → Unassigned highlights what's still not on a circuit.
  7. Link switches. K, click a switch, then every light or outlet it controls. Shift-click a second switch to make a 3-way pair; stairs work across floors.
  8. Print. Print view → Letter or 11×17 → untick sheets you don't need → Print / Save as PDF…. In Chrome's dialog choose Save as PDF and tick Background graphics for colors.

Device numbers

Every device has a permanent number. Once it's on a breaker, its full code adds the panel and breaker.

M7-R103
■ panel code■ breaker slot■ device type■ floor■ sequence

= Main panel, breaker 7 · outlet · floor 1 · #03

Type letters

Routlet
V240V
Ehardwired
Sswitch
Llight / fan
TVcable
Ddata
  • Panel codes are 1–3 letters set in each panel's header: M Main, S Sub, S2 a second sub.
  • 2-pole breakers use their first slot (Range on 3/5 → M3).
  • A device not yet on a breaker shows just its number (R103). Moving it to another circuit changes only the breaker part.
  • Codes appear on the plan (toolbar Labels), on the right panel, in each breaker's device list, and in the printed circuit table.

Tips

  • Device numbers and labels show on the plan only when zoomed in; zoom out for a clean view.
  • Solid symbols are verified circuits; dashed ones aren't tested yet. Changing a device's circuit clears its verified flag.
  • Select a switch to see dashed lines to everything it controls; select a light to see its switches.
  • Use 11×17 paper for floor plans when device codes crowd on Letter.
